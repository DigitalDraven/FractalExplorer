Shading
The trap point (default: origin) is what the overlapping bubbles are centered around. Moving it re-arranges the whole pattern. The actual spread of trap-distances visible in frame shrinks unpredictably as you zoom in, so a fixed "Bubble size" quickly becomes wrong — with "Auto bubble size" on (recommended), it's measured fresh from what's actually on screen each render, and "Repeats" controls how many times the palette cycles across that measured range once "Repeat gradient" is also on. Turn auto off to set "Bubble size" by hand instead. "Smooth blend" fades through Stop A → B → C each cycle; the "Alternating" options hard-switch every band with no blending — 2-color rotates just Stop A / Stop C, 3-color rotates through Stop A / Stop B / Stop C. "Hue shift" rotates which color lands where. Repeated bands are normally flat concentric rings around the trap point, which can look pasted on rather than following each bubble's curve — "Band warp" nudges the bands using the same lighting normal that shades the spheres, so they bend around the dome instead of staying perfectly flat.
Stop A shades the shadows, Stop C shades the highlights. Try the "Bubble / egg" preset above as a starting point.
Detail
Deeper zooms need more iterations to resolve new detail — with auto iterations on, this ramps up automatically as you zoom. Turn it off to set a fixed value yourself.
